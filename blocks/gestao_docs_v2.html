Gestão Estratégica & Inteligência (War Room)

O módulo de Gestão Estratégica transforma diagnósticos em planos de ação. Ele é o "cérebro" da clínica, utilizando IA para sugerir projetos e a metodologia OKR para garantir que a estratégia saia do papel.

1. Visão Macro (O Fluxo de Valor)

O sistema funciona em cascata. Nada é criado por acaso; tudo nasce de um diagnóstico.

2. Diagnóstico (Os 6 Pilares)

Ao iniciar, o gestor responde a um questionário que avalia a saúde da clínica em 6 dimensões. O sistema calcula um Score (0-100) para cada pilar.

1. Atração (CAC)

Marketing e Canais.
"Quantos leads chegam?"

2. Conversão

Comercial e Vendas.
"Quantos viram pacientes?"

3. Produtos (LTV)

Serviços e Recorrência.
"Quanto gastam?"

4. Jornada

NPS e Experiência.
"Eles saem felizes?"

5. Financeiro

Margem e Caixa.
"A conta fecha?"

6. Gestão

Liderança e Cultura.
"O time joga junto?"

3. Inteligência Artificial (N8N)

O Proxy de IA (`proxy_n8n.php`) conecta o PHP ao N8N, que por sua vez orquestra o GPT-4o. O fluxo é totalmente seguro e assíncrono.

sequenceDiagram participant User as Usuário participant PHP as Backend PHP participant N8N as Workflow N8N User->>PHP: Solicita "Gerar Projeto com IA" PHP->>N8N: POST (Pilar Fraco + Contexto) N8N->>N8N: Consulta OpenAI (GPT-4o) N8N->>N8N: Formata JSON Estruturado N8N-->>PHP: Retorna { projeto, explicacao, okrs[] } PHP-->>User: Renderiza Preview na Tela
JSON Estruturado: A IA não retorna texto livre. Ela retorna um objeto JSON contendo Objetivos, Resultados Chave e Tarefas, que o PHP insere nas tabelas correspondentes automaticamente.
4. Modelagem de Dados (Schema)

A estrutura de banco de dados suporta a hierarquia complexa de OKRs e gestão de tarefas.

erDiagram GESTAO_PROJETOS ||--|{ GESTAO_OBJETIVOS : possui GESTAO_OBJETIVOS ||--|{ GESTAO_RESULTADOS_CHAVE : mede GESTAO_OBJETIVOS ||--|{ GESTAO_TAREFAS : executa GESTAO_PROJETOS { int id PK string nome "ex: Implantação CRM" string pilar_foco "ex: Conversao" text descricao_md "Markdown" enum status "planejamento, ativo..." } GESTAO_OBJETIVOS { int id PK int projeto_id FK string titulo "O que conquistar?" date prazo int progresso "0-100" } GESTAO_RESULTADOS_CHAVE { int id PK int objetivo_id FK string titulo "Indicador X" float meta_alvo float atual string unidade "%, R$, un" }
Tabelas Principais:
  • gestao_projetos: A iniciativa macro (Pai de todos).
  • gestao_objetivos: O Sonho (Qualitativo). Vinculado ao Projeto.
  • gestao_resultados_chave: A Meta (Quantitativo). Vinculado ao Objetivo.
Tabelas Operacionais:
  • gestao_tarefas: Cartão do Kanban.
  • gestao_diagnostico: Histórico de avaliações dos 6 pilares.
5. Execução (Task Board)

Para o dia a dia, utilizamos um quadro Kanban visual.

Status do Kanban:
[ BACKLOG ] -> [ FAZER HOJE ] -> [ EM ANDAMENTO ] -> [ REVISÃO ] -> [ CONCLUÍDO ]

Cada tarefa pode ter:

  • Responsável: Usuário do sistema (FK `usuario_id`).
  • Prioridade: Baixa, Média, Alta (Cores visuais).
  • Checklist: Sub-itens dentro do cartão.
