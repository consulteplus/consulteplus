Gestão Estratégica 2.0 (War Room)

O módulo de Gestão Estratégica é o "cérebro" de negócios da clínica. Ele transforma diagnósticos e dados brutos em planos de ação executáveis, utilizando IA para sugerir caminhos e OKRs para medir progresso.

1. Arquitetura em 4 Camadas

O sistema funciona como uma cascata de decisão:

graph TD A[1. Diagnóstico] -->|IA Analisa| B[2. Projetos (War Room)] B -->|Planejamento| C[3. OKRs (Objetivos + KRs)] C -->|Execução| D[4. Tarefas (Kanban)] D -->|Feedback| A
2. Diagnóstico (Os 6 Pilares)

Todo projeto nasce de uma necessidade real. O sistema utiliza 6 pilares fundamentais para avaliar a saúde do negócio (Score 0 a 100):

1. Atração (CAC)

Marketing, Leads, Canais de Aquisição.
"Quantas pessoas novas chegam?"

2. Conversão

Vendas, Scripts, Follow-up.
"Quantos visitantes viram pacientes?"

3. Produtos (LTV)

Mix de Serviços, Precificação, Recorrência.
"Quanto o paciente gasta?"

4. Jornada

Experiência do Paciente, NPS, Retenção.
"O paciente sai feliz?"

5. Financeiro

Margem, Custos, Fluxo de Caixa.
"A conta fecha no azul?"

6. Gestão & Pessoas

Liderança, Cultura, Processos.
"O time está engajado?"

Cálculo de Maturidade: A IA analisa as respostas do formulário de cada pilar e atribui uma nota. Notas abaixo de 60% disparam sugestões automáticas de projetos de correção.
3. Integração com IA (N8N)

O "cérebro" da operação roda no N8N. O fluxo é:

  1. Usuário preenche Diagnóstico ou pede sugestão de Projeto.
  2. PHP envia Prompt Contextualizado (contendo respostas + pilares fracos) para webhook N8N.
  3. N8N consulta OpenAI (GPT-4o).
  4. IA retorna JSON estruturado contendo:
    • nome_projeto
    • descricao (Markdown)
    • okrs (Objetivos + Key Results)
    • tarefas (Ações práticas)
  5. PHP renderiza "Preview" para aprovação do usuário.
4. Hierarquia de Execução

Diferente de sistemas simples de To-Do, aqui a estrutura é rígida para garantir foco:

Nível O que é? Exemplo
1. Projeto A iniciativa macro, com início e fim. "Implantação de Máquina de Vendas"
2. Objetivos A direção qualitativa (Onde queremos chegar). "Garantir previsibilidade de receita"
3. KRs (Key Results) O indicador quantitativo (Como medimos). "Aumentar conversão de 10% para 25%"
4. Tarefas A ação unitária diária. "Configurar CRM", "Treinar recepcionista"
5. Kanban & Execução

As tarefas caem num quadro visual (Kanban) divididas por status:

  • A Fazer Backlog priorizado.
  • Em Andamento Foco da semana.
  • Revisão Aguardando aprovação.
  • Concluído Entrega de valor.

Dica de Uso: Use o filtro por "Responsável" na War Room para ver apenas o que é seu.

Modelo Mental de Guerra

Chamamos de "War Room" porque é onde a estratégia encontra o campo de batalha. Não é lugar de brainstorming, é lugar de acompanhar o avanço das tropas (tarefas) rumo à vitória (KRs).
