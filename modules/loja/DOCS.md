# Documentação do Módulo Loja

**Caminho**: `modules/loja/`

## 1. Visão Geral
Aparentemente é um módulo incompleto ou um endpoint de API isolado. A listagem de produtos da loja para o usuário final parece ocorrer em `modules/produtos/?view=loja`. Este diretório pode ser um resquício ou backend específico.

## 2. Conteúdo
-   `criar_pagamento.php`: Script para iniciar checkout ou pagamento de um item da loja.

## 3. Observação
Recomenda-se verificar se a lógica de loja está centralizada em `modules/produtos` ou fragmentada.
